# Working agreement

- Build exactly what `SPEC.md` describes. You work alone and unattended: never ask questions, never wait for confirmation; make reasonable decisions and record them in `DECISIONS.md`.
- Parallelize: split independent modules across subagents (Task tool) and run them concurrently; integrate and review their work yourself.
- Commit to git after every meaningful milestone with a descriptive message.
- Run tests, lint and typecheck often; fix what fails before moving on.
- Do not reduce scope, skip features, or weaken tests to finish sooner.
